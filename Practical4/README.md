# Practical 4 — Online Event Registration

ASP.NET Web Forms app for event registration with client-side and server-side validation.

## How to Run
Open `Practical4.slnx` in Visual Studio and press `F5`.

## Concepts
- ASP.NET Web Forms (`aspx` + code-behind)
- Validation controls (RequiredFieldValidator, RegularExpressionValidator, CustomValidator)
- Client-side validation with JavaScript
- Server-side validation with `Page.Validate()` and `Page.IsValid`
