# Practical 6 — Product Catalog

ASP.NET MVC application for displaying a product catalog with master-detail navigation using models, controllers, and razor views.

## How to Run
Open `Practical6.slnx` in Visual Studio and press `F5`.

## Concepts
- ASP.NET MVC Architecture (Model, View, Controller)
- Strongly-typed Razor Views (`@model`)
- Master-Detail navigation using `@Html.ActionLink`
- Route configuration and default route mapping (`RouteConfig.cs`)
- In-memory data passing from Controller to View via `List<Product>`
