# Practical 5 — Leave Application

ASP.NET Web Forms multi-page app for employee leave application with master page and navigation between forms.

## How to Run
Open `practical5.slnx` in Visual Studio and press `F5`.

## Concepts
- ASP.NET Web Forms (`aspx` + code-behind)
- Multi-page navigation (Leave Application → Leave Date)
- Master Page / page transitions
- Server-side controls (`TextBox`, `DropDownList`, `Label`, `Button`)
- Cross-page state transfer between Web Forms
